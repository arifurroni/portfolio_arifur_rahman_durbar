Todo App

Tech Stack

HTML5 CSS3 JavaScript (ES6) Local Storage

Description

A dynamic to-do application built with vanilla JavaScript that helps users track their daily tasks. Users can add, edit, delete, and mark tasks as complete. All tasks are persisted using the browser's Local Storage, so data is preserved even after the page is refreshed.

Challenges Faced

  • Managing dynamic DOM updates efficiently as tasks are added and removed.
  • Persisting task state with Local Storage and correctly parsing the stored JSON data.
  • Handling edge cases such as empty inputs, duplicate tasks, and long task names.

Future Improvements

  • Add task categories and due dates with priority levels.
  • Implement drag-and-drop reordering of tasks.
  • Add a dark mode and custom themes.
  • Sync tasks with a backend (MongoDB) so they follow the user across devices.
