Weather Application

Tech Stack

HTML5 CSS3 JavaScript (ES6) OpenWeatherMap API Fetch API

Description

A real-time weather application that shows weather information for any city around the world. Users simply type a city name and the app fetches live data — including temperature, humidity, wind speed, and general conditions — from the OpenWeatherMap API and displays it in a clean, readable interface.

Challenges Faced

  • Handling asynchronous API calls with the Fetch API and managing loading states.
  • Writing proper error handling for invalid city names, network failures, and API rate limits.
  • Displaying dynamic, unstructured API data in a clean and user-friendly layout.

Future Improvements

  • Add automatic location detection using the browser Geolocation API.
  • Show a 7-day weather forecast.
  • Add unit toggling between Celsius and Fahrenheit.
  • Display weather icons and background images that match current conditions.
